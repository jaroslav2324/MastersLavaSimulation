# MastersLavaSimulation

## Описание проекта

Этот репозиторий содержит реализацию метода симуляции лавы в реальном времени на GPU, основанную на методе симуляции жидкости Position-Based Fluids (PBF). Проект демонстрирует реализацию ключевых свойств лавы, включая теплообмен и теплопотерю, температурно-зависимую вязкость и процесс застывания.

## Ключевые особенности

- **Real-time GPU simulation**: Симуляция выполняется на графическом процессоре.
- **Свойства лавы**:
  - Теплообмен и теплопотеря
  - Температурно-зависимая вязкость
  - Застывание лавы
- **Сортировка частиц**: Используется эффективная one-sweep radix сортировка из репозитория [GPUSorting](https://github.com/b0nes164/GPUSorting) для оптимизации вычислений.
